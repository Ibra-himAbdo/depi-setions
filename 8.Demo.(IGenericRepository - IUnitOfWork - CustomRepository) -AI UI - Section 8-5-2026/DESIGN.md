# Design

## Theme
- **Primary Theme**: `corporate` (DaisyUI 5)
- **Alternate Theme**: `nord` / `business` (available via data-theme)
- **Surface**: `bg-base-100` for main content, `bg-base-200` for cards and sidebars.

## Palette
- **Primary**: Corporate Blue (Trust, Professionalism)
- **Secondary**: Slate / Neutral (Clean, High-contrast)
- **Accent**: Emerald / Cyan (Success, AI Intelligence)

## Typography
- **Headings**: Semibold, high-contrast, slightly larger than default (1.25x ratio).
- **Body**: Standard sans-serif (Inter/Roboto), 16px base, 75ch max width for readability.

## Components
- **Buttons**: `btn` with `btn-sm` for actions, `btn-lg` for hero/primary calls.
- **Cards**: `card bg-base-200 shadow-xl` with clean padding.
- **Tables**: `table-zebra` with rounded-lg borders.
- **AI Bubbles**: `chat-bubble-primary` for AI, `chat-bubble-secondary` for User.

## Layout
- **Navigation**: Drawer-based for mobile, Navbar-based for desktop.
- **Spacing**: Consistent 1rem (4 units) padding/margin blocks.
- **Motions**: `ease-out-expo` for transitions.
