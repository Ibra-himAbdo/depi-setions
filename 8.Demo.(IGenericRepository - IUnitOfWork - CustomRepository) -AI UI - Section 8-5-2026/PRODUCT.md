# Product

## Register

product

## Users
Developers and students learning modern .NET architectures (Generic Repository, Unit of Work) who want to see how these patterns integrate with cutting-edge AI features (Groq, Microsoft Extensions AI).

## Product Purpose
A high-fidelity demonstration project that bridges traditional enterprise patterns with modern AI-driven user interfaces. It aims to show that "Enterprise" doesn't have to mean "Ugly", by using DaisyUI 5 and Tailwind CSS 4 to create a premium experience.

## Brand Personality
Expert, Professional, Modern, Reliable. It feels like a high-end SaaS tool (Linear, Vercel) but for learning repository patterns.

## Anti-references
- Generic Bootstrap "Admin LTE" templates.
- Cluttered, multi-colored legacy dashboards.
- Slow, non-responsive table layouts.

## Design Principles
- **Pattern First**: Design should highlight the underlying data structures (Products, Brands, Categories).
- **AI-Native**: The AI shouldn't feel like an afterthought; it should be integrated into the core navigation.
- **Micro-interactions**: Use DaisyUI transitions and Tailwind animations to make the UI feel alive.

## Accessibility & Inclusion
- Full RTL support (built-in).
- WCAG AA contrast levels using DaisyUI semantic colors.
